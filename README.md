# デカマゴカウンター

ポケモンスリープで「おおきなマゴのみ」を拾ってきた回数を数える、かちかちくん（スロットの数取器）風のカウンター。

- 公開URL: https://akirahaan-blip.github.io/pksl.dekamago-counter/
- ファイルは `index.html` の1枚だけ（HTML / CSS / JavaScript が全部入っている）

## できること

- チームの5匹ぶんのボタン。分類（ミュウ／ミュウツー／エスパー／それ以外）を選ぶとボタンの色が決まる
  - ミュウとミュウツーは同じチームに入れられないので、片方を選ぶともう片方は選べなくなる
- 横長の液晶に、合計（TOTAL）と5匹それぞれの数を7セグメント表示
- 押すたびに「いつ・何匹目・分類・そのときの名前」を履歴に残す（名前を変えても過去の記録はそのまま）
- 「−1」で直前の1回を取り消し、「リセット」は2回押しで0に
- カチッという音（ON/OFF できる）
- 「↻ 横向きで使う」で画面を90度回して、スマホを横に持って使える
- 数・設定・履歴はブラウザの localStorage に保存（サーバーには送らない）

## 直したいとき

`index.html` をメモ帳などで開いて直し、`公開手順.md` のとおりに GitHub へ反映する。
